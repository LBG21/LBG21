# Personal website

Published at https://lbg21.github.io/LBG21/ using the original **Academic Pages / Minimal Mistakes** Jekyll template.

The website contains only **About** and **Research**. Template typography, colors, profile sidebar, and layout are retained. Liber-0 is credited to **LiberAI Team**.

## Edit content

- `_pages/about.md`: biography and research interests.
- `_pages/research.md`: publications and project links.
- `_config.yml`: profile, email, Google Scholar, and GitHub links.
- `_data/navigation.yml`: the two navigation entries.
- `images/avatar.jpg`: the original portrait.

Other template example pages and collections are excluded from publication. The original source remains in the repository.

## Publish

GitHub Pages uses the **master** branch and the repository root (`/`). Push changes to `master` to trigger publication. `_config.yml` uses `url: https://lbg21.github.io` and `baseurl: /LBG21` for this repository's Pages address.

For local Jekyll preview, install the Gemfile dependencies and run `bundle exec jekyll serve`. No custom frontend framework or build system has been added.
